# Asteroids tests

`test_harness_baseline.py` covers pure game logic that doesn't need a
display surface — `pygame.Vector2`/`Sprite` math works headlessly, rendering
does not, so this is the only test coverage this repo has:

- Asteroid radius: max radius derives correctly from kind count.
- Collision detection: overlapping, far apart, and exact-touching-edge cases.
- Screen wraparound: left↔right and top↔bottom edges, plus a no-op check
  for a shape that's still fully onscreen.

Per the module's own docstring, this file doubles as ground truth for
`scripts/eval-local-model.sh` in the `claude-daemon` workspace to grade
model-generated changes against — note that script was removed 2026-09-08
(see that workspace's `notes/context/aider-status.md`), so this reference is
now stale.

`conftest.py` is a plain 4-line file that inserts the parent directory onto
`sys.path` so the test files can `import` this project's top-level modules
directly — nothing more, not generated by anything.
